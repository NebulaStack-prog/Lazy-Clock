## Часть 1. Основной документ.

### 1. Заголовок и базовая информация.

• **Название:** Lazy Clock

• **Назначение:** Проект № 11. Продукт.

• **Фаза проекта:** Phase II.

• **Технологический стек:** Python (библиотека PySide6).

• **Статус проекта:** Полностью завершен.

### 2. Краткое описание проекта.

**Lazy Clock** – это десктопное приложение-часы, созданное на языке Python с использованием библиотеки PySide6 (Qt for Python).

Приложение отображает аналоговые часы с плавно движущимися стрелками (часовая, минутная и секундная) на прозрачном фоне без рамок окна.

Ключевой особенностью является интеграция с системным треем, что позволяет управлять отображением часов, закреплять их поверх других окон и завершать работу приложения через контекстное меню.

Проект представляет собой полностью функциональное приложение с продуманным минималистичным интерфейсом и удобным управлением.

### 3. Четкие цели проекта.

• Создать работающее приложение-часы с аналоговым циферблатом.

• Реализовать плавное движение стрелок с высокой частотой обновления (60 FPS).

• Обеспечить отображение часов на прозрачном фоне без стандартной рамки окна.

• Реализовать возможность перетаскивания часов по рабочему столу с помощью мыши.

• Интегрировать приложение с системным треем для управления его состоянием.

• Добавить функцию закрепления часов поверх всех окон.

• Реализовать корректное завершение работы приложения как через трей, так и через системные сигналы (SIGINT, SIGTERM).

• Продемонстрировать подход к разработке десктопных приложений с использованием PySide6 и QSystemTrayIcon.

### 4. Компоненты проекта.

• Проект состоит из одного исполняемого файла, который включает в себя все компоненты:

• lazy_clock.py – основной скрипт, содержащий весь код приложения, включая логику отрисовки, обработку событий мыши, управление окном и интеграцию с системным треем.

### 5. Инструкция по использованию.

**5.1. Запуск:**

• Убедитесь, что установлена библиотека PySide6 (pip install PySide6).

• Запустите скрипт с помощью Python (например, с помощью PyCharm).

**5.2. Цель приложения:**

• Отображение текущего времени в виде аналоговых часов на рабочем столе.

• Приложение может работать в фоновом режиме, оставаясь доступным через иконку в системном трее.

**5.3. Управление:**

• Левая кнопка мыши (удержание и перетаскивание): перемещение часов по рабочему столу.

• Двойной клик по иконке в трее: показать/скрыть часы.

• Контекстное меню трея (правый клик):

- Показать/скрыть часы: переключение видимости окна часов.
  
- Поверх всех окон: закрепление/снятие закрепления часов поверх других окон.

- Выйти: полное завершение работы приложения.

**5.4. Интерфейс:**

• Окно часов размером 700x700 пикселей.

• Прозрачный фон без рамки окна (FramelessWindowHint, WA_TranslucentBackground).

• Три стрелки:

- Часовая – черная (#111111), длина 140, толщина 12.
  
- Минутная – темно-серая (#222222), длина 200, толщина 8.

- Секундная – красная (#d22), длина 235, толщина 2.

• Центральный круг черного цвета радиусом 8 пикселей.

• Иконка в системном трее – синий круг (#3498db) на прозрачном фоне.

## Часть 2. Технический документ.

### 1. Цели разработки.

• Основной целью разработки было создание десктопного приложения-часов с использованием современной библиотеки PySide6 для закрепления навыков работы с Qt.

• Дополнительно проект направлен на изучение создания прозрачных окон без рамок, интеграции с системным треем, обработки событий мыши и системных сигналов.

• Задачи включали работу с QPainter для кастомной отрисовки, QTimer для анимации, QSystemTrayIcon для управления приложением и QMenu для контекстного меню.

### 2. Использованные технологии.

• **Язык программирования:** Python

• **Графическая библиотека:** PySide6 (Qt for Python)

• **Стандартные библиотеки:** sys (для работы с аргументами и завершением), signal (для обработки системных сигналов), math (для вычисления координат стрелок), datetime (для получения текущего времени).

• **Модули PySide6:**

- QtCore: Qt, QPoint, QTimer.
  
- QtGui: QColor, QPainter, QPen, QAction, QIcon, QPixmap.
  
- QtWidgets: QApplication, QWidget, QSystemTrayIcon, QMenu, QMainWindow.

### 3. Архитектура проекта.

• Проект реализован как приложение с разделением на два основных класса: ClockWidget (отрисовка часов) и MainWindow (управление приложением и треем).

• Основной цикл: событийно-ориентированный, управляемый QApplication.exec().

• Логика разделена по классам:

- ClockWidget – отвечает за отрисовку, анимацию и перетаскивание.
  
- MainWindow – отвечает за создание трея, обработку меню и системных сигналов.

• В каждом кадре (60 FPS) выполняется: получение текущего времени, вычисление углов стрелок, отрисовка циферблата.

### 4. Структура проекта.

• Инициализация: настройка PySide6, создание QApplication, установка setQuitOnLastWindowClosed(False).

• **Класс ClockWidget:**

- __init__(always_on_top=False) – настройка окна, флагов, таймера.
- paintEvent(event) – отрисовка стрелок и центра.
  
- draw_hand(...) – вспомогательный метод для рисования стрелки.
  
- mousePressEvent(event) – начало перетаскивания.
  
- mouseMoveEvent(event) – перемещение окна.

• **Класс MainWindow:**

- __init__() – создание ClockWidget, трея, подключение сигналов.
  
- signal_handler(signum, frame) – обработка SIGINT/SIGTERM.
  
- create_tray_icon() – создание иконки и меню трея.
  
- tray_clicked(reason) – обработка кликов по трею.

- toggle_clock() – показать/скрыть часы.
  
- toggle_top(checked) – закрепить/снять поверх всех окон.
  
- quit_app() – корректное завершение.

• Точка входа: if __name__ == "__main__": – создание приложения, окна, запуск.

• Глобальные переменные: отсутствуют (все состояние инкапсулировано в классах).

### 5. Ключевые компоненты системы.

• **Отрисовка часов (paintEvent):** Использование QPainter с Antialiasing для сглаживания. Вычисление углов стрелок на основе текущего времени с учетом микросекунд для плавности.

• **Стрелки:** Представлены как линии, рисуемые drawLine с RoundCap. Углы: часовая – hour * 30, минутная – minute * 6, секундная – sec * 6.

• **Система анимации:** QTimer с интервалом 1000 // 60 (≈16.67 мс) вызывает update() 60 раз в секунду.

• **Перетаскивание окна:** Реализовано через сохранение глобальной позиции мыши при нажатии и вычисление смещения при движении.

• **Системный трей:** QSystemTrayIcon с контекстным меню QMenu, содержащим QAction для управления.

• **Обработка сигналов:** signal.signal(signal.SIGINT, ...) и signal.SIGTERM для корректного завершения при прерывании из терминала.

### 6. Реализация пользовательского интерфейса.

• Интерфейс полностью реализован средствами PySide6.

• Основные элементы: окно часов (прозрачное, без рамки), иконка в трее, контекстное меню.

• Отрисовка выполняется через QPainter в paintEvent с использованием QPen и drawEllipse.

• Иконка трея создается программно через QPixmap и QPainter.

### 7. Процесс разработки.

• Разработка велась поэтапно:

- создание базового окна с прозрачным фоном.
  
- реализация отрисовки циферблата и стрелок.
  
- добавление таймера для анимации.
  
- реализация перетаскивания окна мышью.
  
- интеграция с системным треем.
  
- добавление меню трея (показать/скрыть, поверх всех, выход).
  
- реализация закрепления поверх окон.

- обработка системных сигналов для корректного завершения.

### 8. Основные сложности и способы их решения.

• **(1) Сложность:** корректное перетаскивание окна без рамки.

**Решение:** использование event.globalPosition().toPoint() для получения глобальных координат и вычисления смещения относительно self.pos().

• **(2) Сложность:** плавное движение секундной стрелки.

**Решение:** учет микросекунд при вычислении угла (sec = now.second + now.microsecond / 1000000).

• **(3) Сложность:** корректное завершение приложения при закрытии через трей.

**Решение:** установка app.setQuitOnLastWindowClosed(False) и явный вызов QApplication.quit() в quit_app().

• **(4) Сложность:** обработка системных сигналов в Qt-приложении.

**Решение:** подключение signal.signal к кастомному обработчику signal_handler, который вызывает quit_app().

### 9. Текущие ограничения проекта.

• Отсутствие цифрового отображения времени.

• Нет возможности настройки размера, цвета или стиля часов.

• Нет звуковых уведомлений (будильника).

• Код остается монолитным (без разделения на модули).
